# AutoCrys v1.0

**Author: Shitao Wu · Affiliation: ShanghaiTech**

Automated 3D electron diffraction workflows for processing, reconstruction,
structure solution and refinement.

- Includes AutoXDS, AutoDials, AutoR3D, AutoSolve, AutoRefine and the integrated UI.
- Downloads: source ZIP/TAR.GZ, Python wheel (1.0.0), and SHA256SUMS.txt.
- Requires Python 3.12 or later. See [GETTING_STARTED.md](GETTING_STARTED.md)
  for Windows + WSL/Linux deployment and external-program setup.
- Data/Demo, personal settings, API keys and third-party executables are excluded.
  Obtain SHELXT/SHELXL and XDS independently from their official providers;
  optional DIALS/Olex2 must also be installed separately.
- Offline acceptance: 149 tests, 133 passed, 16 skipped, no failures or errors.
  Skipped checks need experimental data, external programs or optional services.
  Real experimental workflows have not been validated for this distribution.
